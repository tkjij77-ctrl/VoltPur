# قياسات مُوثّقة (Measurements)

كل رقم يُنشر في README أو أي وثيقة **يجب** أن يكون له ملف هنا، بهذا القالب:

```markdown
# <اسم التغيير> — <التاريخ>
- البناء: build #<n> (<sha>)   |  Java: <version>   |  الحصة: <RAM MB> / <cores>
- إعداد المقارنة: نفس العالم، نفس عدد اللاعبين (<n>)، مدة <دقائق>
- قبل: MSPT=<a> TPS=<b> (3 قياسات: <..>)
- بعد: MSPT=<a'> TPS=<b'> (3 قياسات: <..>)
- الفرق: <x%>  |  هامش الضوضاء المتوقع: ±5%
- الملف الخام: `logs/voltpur-benchmark.txt` (مُرفق في الإصدار)
- الحكم: مقبول / مرفوض (لأن ...)
```

**قاعدة:** لو الملف مش موجود، الرقم يُسحب من التوثيق (انظر `docs/BENCHMARKS.md` قسم «أرقام مسحوبة»).
